# Materials

All endgame materials used by Endgame & QoL and where to find them.

## Hides & leather

### Storm Hide

<img src="https://raw.githubusercontent.com/lewai1/endgameqolwiki/main/images/icons/Ingredient_Hide_Storm.png" width="72" style="float:left;margin:0 14px 8px 0;"> Key crafting material used in most Mithril and Onyxium recipes (via Storm Leather).

<div style="clear:both;"></div>

| Source | Quantity |
| --- | --- |
| Dragon Frost | 3–6 (40 %) |
| Yeti (vanilla) | 1–3 |
| Werewolf | 1 |
| Onyxium Encounter | 2–3 |
| Zone 4 Sewers chests | 1–3 |
| Frozen Dungeon towers | 1–3 |
| Frozen Dungeon hidden chests | 1–4 |
| Frozen Dungeon Dragon Zone | 3–5 |
| Warden Trial I / II / III / IV | 2–4 / 3–5 / 4–7 / 5–8 |

**Craftable** — 4× Cindercloth Scrap + 3× Heavy Leather + 3× Shadoweave Scrap + 3× Sturdy Chitin (Endgame Bench Tier 3).

### Prismic Hide

<img src="https://raw.githubusercontent.com/lewai1/endgameqolwiki/main/images/icons/Ingredient_Hide_Prismic.png" width="72" style="float:left;margin:0 14px 8px 0;"> Highest-tier leather, required for Prisma armor.

<div style="clear:both;"></div>

**Craft only** — 4× Storm Leather + 3× Heavy Leather + 3× Shadoweave Scrap + 3× Ice Essence (Endgame Bench Tier 4). Storm Leather is tanned from Storm Hide at the Tannery.

### Apex Sovereign Leather

Tough leather from the Alpha Rex.

| Source | Quantity |
| --- | --- |
| Alpha Rex | 2–3 |

### Sturdy Chitin

Tough exoskeleton plates from Scarak fighters. Used in Storm Hide crafting.

| Source | Quantity |
| --- | --- |
| Scarak Fighter | 1–2 |

## Bars & ores

<img src="https://raw.githubusercontent.com/lewai1/endgameqolwiki/main/images/icons/Ingredient_Bar_Prisma.png" width="72" style="float:left;margin:0 14px 8px 0;"> The rarest crafting bar, required for all Prisma-tier equipment.

<div style="clear:both;"></div>

**Mob drops**

| Source | Quantity |
| --- | --- |
| Golem Void | Weighted drop — ≈60 % Onyxium (6–10) / 40 % Prisma (3–7) |

**Warden's Trial rewards**

| Tier | Quantity |
| --- | --- |
| III | 1–3 |
| IV | 3–6 |

**Craftable** — 1× Mithril Bar + 1× Onyxium Bar + 1× Emerald (Endgame Bench Tier 5). Also tradeable at the Vorthak shop.

## Void materials

| Source | Quantity |
| --- | --- |
| Zombie Aberrant | 1 |
| Spectre Void | 1 |
| Hedera | 1 |
| Shadow Knight | 1 |
| Void Necromancer | 1 |
| Onyxium Encounter | 1 |
| Warden Trial II / III / IV | 1–2 / 2–4 / 4–7 |

### Void Blocks

<img src="https://raw.githubusercontent.com/lewai1/endgameqolwiki/main/images/icons/Endgame_Void_Block.png" width="72" style="float:left;margin:0 14px 8px 0;"> The decorative void block line — 10 placeable blocks crafted from **Void Essence** + **Rock** at the **Endgame Bench** (Void Blocks category, bench Tier 1). Recipes unlock all at once via the **Void Architect's Tome** (Epic drop from the Void Realm loot chests). `Void Block` is the hub the rest branch from.

<div style="clear:both;"></div>

| Block | Recipe | Yield |
| --- | --- | :---: |
| Void Block | Rock ×4 + Void Essence ×1 | 4 |
| Void Brick | Rock ×2 + Void Essence ×4 | 4 |
| Void Core *(glows)* | Void Block ×4 + Void Essence ×1 | 4 |
| Void Ancient Stone | Void Block ×4 + Void Essence ×2 | 4 |
| Corrupted Block | Void Block ×4 + Void Essence ×2 | 4 |
| Void Light · Brick Light · Core Light · Ancient Light · Corrupted Light | *base block* ×1 + Void Essence ×1 | 1 |

See [Void Realm](void-realm) for the dimension where Void Essence is farmed.
